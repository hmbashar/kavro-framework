# Kavro Framework Static Website

This is a responsive static HTML documentation/marketing website for Kavro Framework, ready for GitHub Pages.

## Included

- `index.html` premium homepage
- `docs/index.html` documentation hub
- module documentation pages
- `144` dedicated field pages under `docs/fields/`
- shared assets under `assets/`
- original Markdown source copied under `markdown-source/`

## Deploy to GitHub Pages

Upload these files to your GitHub Pages branch/root and enable Pages from repository settings.
