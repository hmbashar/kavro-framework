# `dimensions_advanced` Field

## Purpose

The `dimensions_advanced` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_dimensions_advanced',
    'type'  => 'dimensions_advanced',
    'title' => 'Dimensions Advanced',
)
```
