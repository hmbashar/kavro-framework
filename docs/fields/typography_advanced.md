# `typography_advanced` Field

## Purpose

The `typography_advanced` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_typography_advanced',
    'type'  => 'typography_advanced',
    'title' => 'Typography Advanced',
)
```
