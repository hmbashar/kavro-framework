# `permission_matrix` Field

## Purpose

The `permission_matrix` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_permission_matrix',
    'type'  => 'permission_matrix',
    'title' => 'Permission Matrix',
)
```
