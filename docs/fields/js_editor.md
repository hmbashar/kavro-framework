# `js_editor` Field

## Purpose

The `js_editor` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_js_editor',
    'type'  => 'js_editor',
    'title' => 'Js Editor',
)
```
