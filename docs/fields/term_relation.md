# `term_relation` Field

## Purpose

The `term_relation` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_term_relation',
    'type'  => 'term_relation',
    'title' => 'Term Relation',
)
```
