# `menu_select` Field

## Purpose

The `menu_select` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_menu_select',
    'type'  => 'menu_select',
    'title' => 'Menu Select',
)
```
