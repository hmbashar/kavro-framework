# `log_viewer` Field

## Purpose

The `log_viewer` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_log_viewer',
    'type'  => 'log_viewer',
    'title' => 'Log Viewer',
)
```
