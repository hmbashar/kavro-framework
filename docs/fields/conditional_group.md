# `conditional_group` Field

## Purpose

The `conditional_group` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_conditional_group',
    'type'  => 'conditional_group',
    'title' => 'Conditional Group',
)
```
