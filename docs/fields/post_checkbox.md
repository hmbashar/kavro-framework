# `post_checkbox` Field

## Purpose

The `post_checkbox` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_post_checkbox',
    'type'  => 'post_checkbox',
    'title' => 'Post Checkbox',
)
```
