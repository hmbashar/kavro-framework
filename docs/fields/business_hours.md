# `business_hours` Field

## Purpose

The `business_hours` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_business_hours',
    'type'  => 'business_hours',
    'title' => 'Business Hours',
)
```
