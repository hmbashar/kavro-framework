# `box_shadow` Field

## Purpose

The `box_shadow` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_box_shadow',
    'type'  => 'box_shadow',
    'title' => 'Box Shadow',
)
```
