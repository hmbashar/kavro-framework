# `shortcode_builder` Field

## Purpose

The `shortcode_builder` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_shortcode_builder',
    'type'  => 'shortcode_builder',
    'title' => 'Shortcode Builder',
)
```
