# `onboarding_steps` Field

## Purpose

The `onboarding_steps` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_onboarding_steps',
    'type'  => 'onboarding_steps',
    'title' => 'Onboarding Steps',
)
```
