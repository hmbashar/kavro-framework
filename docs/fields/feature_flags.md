# `feature_flags` Field

## Purpose

The `feature_flags` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_feature_flags',
    'type'  => 'feature_flags',
    'title' => 'Feature Flags',
)
```
