# `rest_endpoint` Field

## Purpose

The `rest_endpoint` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_rest_endpoint',
    'type'  => 'rest_endpoint',
    'title' => 'Rest Endpoint',
)
```
