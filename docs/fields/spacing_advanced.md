# `spacing_advanced` Field

## Purpose

The `spacing_advanced` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_spacing_advanced',
    'type'  => 'spacing_advanced',
    'title' => 'Spacing Advanced',
)
```
