# `cache_control` Field

## Purpose

The `cache_control` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_cache_control',
    'type'  => 'cache_control',
    'title' => 'Cache Control',
)
```
