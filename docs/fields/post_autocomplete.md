# `post_autocomplete` Field

## Purpose

The `post_autocomplete` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_post_autocomplete',
    'type'  => 'post_autocomplete',
    'title' => 'Post Autocomplete',
)
```
