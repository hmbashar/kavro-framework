# `device_preview` Field

## Purpose

The `device_preview` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_device_preview',
    'type'  => 'device_preview',
    'title' => 'Device Preview',
)
```
