# `wp_editor` Field

## Purpose

The `wp_editor` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_wp_editor',
    'type'  => 'wp_editor',
    'title' => 'Wp Editor',
)
```
