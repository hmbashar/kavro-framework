# `post_relation` Field

## Purpose

The `post_relation` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_post_relation',
    'type'  => 'post_relation',
    'title' => 'Post Relation',
)
```
