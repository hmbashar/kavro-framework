# `tabbed` Field

## Purpose

The `tabbed` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_tabbed',
    'type'  => 'tabbed',
    'title' => 'Tabbed',
)
```
