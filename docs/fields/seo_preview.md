# `seo_preview` Field

## Purpose

The `seo_preview` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_seo_preview',
    'type'  => 'seo_preview',
    'title' => 'Seo Preview',
)
```
