# `color_picker_alpha` Field

## Purpose

The `color_picker_alpha` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_color_picker_alpha',
    'type'  => 'color_picker_alpha',
    'title' => 'Color Picker Alpha',
)
```
