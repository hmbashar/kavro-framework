# `menu_builder` Field

## Purpose

The `menu_builder` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_menu_builder',
    'type'  => 'menu_builder',
    'title' => 'Menu Builder',
)
```
