# `css_editor` Field

## Purpose

The `css_editor` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_css_editor',
    'type'  => 'css_editor',
    'title' => 'Css Editor',
)
```
