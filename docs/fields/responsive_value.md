# `responsive_value` Field

## Purpose

The `responsive_value` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_responsive_value',
    'type'  => 'responsive_value',
    'title' => 'Responsive Value',
)
```
