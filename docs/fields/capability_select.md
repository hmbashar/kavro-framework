# `capability_select` Field

## Purpose

The `capability_select` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_capability_select',
    'type'  => 'capability_select',
    'title' => 'Capability Select',
)
```
