# `taxonomy_radio` Field

## Purpose

The `taxonomy_radio` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_taxonomy_radio',
    'type'  => 'taxonomy_radio',
    'title' => 'Taxonomy Radio',
)
```
