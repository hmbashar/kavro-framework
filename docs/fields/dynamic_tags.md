# `dynamic_tags` Field

## Purpose

The `dynamic_tags` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_dynamic_tags',
    'type'  => 'dynamic_tags',
    'title' => 'Dynamic Tags',
)
```
