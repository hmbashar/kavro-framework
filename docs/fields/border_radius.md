# `border_radius` Field

## Purpose

The `border_radius` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_border_radius',
    'type'  => 'border_radius',
    'title' => 'Border Radius',
)
```
