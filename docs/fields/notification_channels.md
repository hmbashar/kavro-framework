# `notification_channels` Field

## Purpose

The `notification_channels` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_notification_channels',
    'type'  => 'notification_channels',
    'title' => 'Notification Channels',
)
```
