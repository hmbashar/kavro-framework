# `multicheck` Field

## Purpose

The `multicheck` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_multicheck',
    'type'  => 'multicheck',
    'title' => 'Multicheck',
)
```
