# `query_builder` Field

## Purpose

The `query_builder` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_query_builder',
    'type'  => 'query_builder',
    'title' => 'Query Builder',
)
```
