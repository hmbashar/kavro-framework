# `api_credentials` Field

## Purpose

The `api_credentials` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_api_credentials',
    'type'  => 'api_credentials',
    'title' => 'Api Credentials',
)
```
