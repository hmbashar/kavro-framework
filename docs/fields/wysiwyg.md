# `wysiwyg` Field

## Purpose

The `wysiwyg` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_wysiwyg',
    'type'  => 'wysiwyg',
    'title' => 'Wysiwyg',
)
```
