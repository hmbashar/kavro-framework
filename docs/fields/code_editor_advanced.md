# `code_editor_advanced` Field

## Purpose

The `code_editor_advanced` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_code_editor_advanced',
    'type'  => 'code_editor_advanced',
    'title' => 'Code Editor Advanced',
)
```
