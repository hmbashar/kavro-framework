# `enhanced_select` Field

## Purpose

The `enhanced_select` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_enhanced_select',
    'type'  => 'enhanced_select',
    'title' => 'Enhanced Select',
)
```
