# `video_upload` Field

## Purpose

The `video_upload` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_video_upload',
    'type'  => 'video_upload',
    'title' => 'Video Upload',
)
```
