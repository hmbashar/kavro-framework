# `schema_markup` Field

## Purpose

The `schema_markup` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_schema_markup',
    'type'  => 'schema_markup',
    'title' => 'Schema Markup',
)
```
