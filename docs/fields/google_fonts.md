# `google_fonts` Field

## Purpose

The `google_fonts` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_google_fonts',
    'type'  => 'google_fonts',
    'title' => 'Google Fonts',
)
```
