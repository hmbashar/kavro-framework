# `open_graph` Field

## Purpose

The `open_graph` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_open_graph',
    'type'  => 'open_graph',
    'title' => 'Open Graph',
)
```
