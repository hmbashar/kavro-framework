# `cloneable` Field

## Purpose

The `cloneable` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_cloneable',
    'type'  => 'cloneable',
    'title' => 'Cloneable',
)
```
