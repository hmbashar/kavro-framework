# `taxonomy_checkbox` Field

## Purpose

The `taxonomy_checkbox` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_taxonomy_checkbox',
    'type'  => 'taxonomy_checkbox',
    'title' => 'Taxonomy Checkbox',
)
```
