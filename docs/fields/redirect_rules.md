# `redirect_rules` Field

## Purpose

The `redirect_rules` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_redirect_rules',
    'type'  => 'redirect_rules',
    'title' => 'Redirect Rules',
)
```
