# `taxonomy_select` Field

## Purpose

The `taxonomy_select` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_taxonomy_select',
    'type'  => 'taxonomy_select',
    'title' => 'Taxonomy Select',
)
```
