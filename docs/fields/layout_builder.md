# `layout_builder` Field

## Purpose

The `layout_builder` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_layout_builder',
    'type'  => 'layout_builder',
    'title' => 'Layout Builder',
)
```
