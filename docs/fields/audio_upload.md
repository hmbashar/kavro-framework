# `audio_upload` Field

## Purpose

The `audio_upload` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_audio_upload',
    'type'  => 'audio_upload',
    'title' => 'Audio Upload',
)
```
