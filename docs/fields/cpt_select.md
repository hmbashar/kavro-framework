# `cpt_select` Field

## Purpose

The `cpt_select` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_cpt_select',
    'type'  => 'cpt_select',
    'title' => 'Cpt Select',
)
```
