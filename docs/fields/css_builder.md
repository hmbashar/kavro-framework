# `css_builder` Field

## Purpose

The `css_builder` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_css_builder',
    'type'  => 'css_builder',
    'title' => 'Css Builder',
)
```
