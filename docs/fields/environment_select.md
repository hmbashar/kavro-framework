# `environment_select` Field

## Purpose

The `environment_select` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_environment_select',
    'type'  => 'environment_select',
    'title' => 'Environment Select',
)
```
