# `fieldset` Field

## Purpose

The `fieldset` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_fieldset',
    'type'  => 'fieldset',
    'title' => 'Fieldset',
)
```
