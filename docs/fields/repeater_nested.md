# `repeater_nested` Field

## Purpose

The `repeater_nested` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_repeater_nested',
    'type'  => 'repeater_nested',
    'title' => 'Repeater Nested',
)
```
