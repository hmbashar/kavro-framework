# `ajax_select` Field

## Purpose

The `ajax_select` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_ajax_select',
    'type'  => 'ajax_select',
    'title' => 'Ajax Select',
)
```
