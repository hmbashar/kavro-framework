# `rate_limit` Field

## Purpose

The `rate_limit` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_rate_limit',
    'type'  => 'rate_limit',
    'title' => 'Rate Limit',
)
```
