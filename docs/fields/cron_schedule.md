# `cron_schedule` Field

## Purpose

The `cron_schedule` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_cron_schedule',
    'type'  => 'cron_schedule',
    'title' => 'Cron Schedule',
)
```
