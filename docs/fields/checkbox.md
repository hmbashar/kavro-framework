# `checkbox` Field

## Purpose

The `checkbox` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_checkbox',
    'type'  => 'checkbox',
    'title' => 'Checkbox',
)
```
