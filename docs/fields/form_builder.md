# `form_builder` Field

## Purpose

The `form_builder` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_form_builder',
    'type'  => 'form_builder',
    'title' => 'Form Builder',
)
```
