# `sidebar_select` Field

## Purpose

The `sidebar_select` field is available in Kavro option panels and metaboxes.

## Example

```php
array(
    'id'    => 'example_sidebar_select',
    'type'  => 'sidebar_select',
    'title' => 'Sidebar Select',
)
```
