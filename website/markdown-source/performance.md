# Performance

Kavro detects the active field profile and only loads heavy assets when needed.

## Asset loading recommendations

- Load media scripts only for media/upload/image/gallery/file/audio/video fields.
- Load color picker scripts only for color fields.
- Load Select2-style scripts only for select2/ajax/content relationship fields.
- Load date/time picker scripts only for date/time/datetime fields.
- Keep demo examples disabled on production sites.
